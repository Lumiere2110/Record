メモの設定

メモは GitHub の data/records.json に保存されます。保存するには、Record に書き込める GitHub のトークンをこの端末に登録します。

  1. GitHub のトークン作成ページを開く
  2. Repository access で「Only select repositories」→ Record を選ぶ
  3. Permissions の Contents を「Read and write」にする
  4. 作成したトークンを下に貼り付けて「登録」

トークンはこのブラウザの中だけに保存され、GitHub 以外には送られません。メモはサイトと同じく誰でも見られます。
記録は data/records.json にあります。追記のしかたは README を見てください。
